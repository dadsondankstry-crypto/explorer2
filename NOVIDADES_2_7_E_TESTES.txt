Projeto Java Android, offline, pronto para o ZiptoGit: arquivos do projeto estão **na raiz do ZIP**, inclusive `.github/workflows/main.yml`. Preserva os recursos existentes da versão 2.6.

## Novidades: 43 comandos/opções de menu (9 + 23 + 11)

No aplicativo, toque em **🛡 Auditoria 2.7**. As opções dividem-se em três menus. **Vários comandos são variantes de um mesmo motor de análise**; não representam 43 mecanismos independentes. Para arquivos ZIP, continue utilizando as funções ZIP existentes. A auditoria 2.7 destina-se às pastas comuns autorizadas via SAF.

## O que NÃO faz (de propósito)
- Não apaga, move nem altera arquivos dentro das novas funções 2.7. Não é antivírus.
- Não acessa pastas privadas de outros aplicativos; não usa permissão de gerenciamento irrestrito.
- Não recupera arquivos excluídos nem altera datas de criação/modificação.
- Não declara dados incompletos como completos quando o provedor falha ou o limite de busca é ultrapassado.

## Limites e segurança
- Auditoria recursiva: 3.000 entradas e 18 níveis, aborta quando exceder.
- Hash/comparação: máximo 256 MB por arquivo; manifesto: máximo 80 arquivos.
- Duplicados: arquivos até 16 MB; máximo 60 candidatos com tamanho igual. Não afirmar inexistência de duplicados fora desses limites.
- Resultado em tela pode ser truncado. Exportação TXT via seletor nativo do Android (ACTION_CREATE_DOCUMENT).
- Datas são de **última modificação**, quando disponíveis. Arquivos ocultos são considerados em auditoria mesmo que o filtro visual os esconda, desde que o provedor os disponibilize.
- SHA-1 e MD5 disponíveis por compatibilidade; não usar como prova criptográfica segura. Hashes não detectam vírus.
- Pesquisa e checksums são executados em thread de trabalho com cancelamento cooperativo.

## Instalação / compilação
1. Envie **o ZIP original, sem extrair**, para seu repositório usando ZiptoGit.
2. Verifique se `.github/workflows/main.yml` está presente no GitHub.
3. Abra Actions e aguarde a execução terminar com indicador verde.
4. Baixe `ExploradorZIP-APK`, extraia o artefato e instale `app-debug.apk`.
5. Se Android acusar assinatura diferente, isso decorre do APK de depuração do GitHub Actions; para atualizações confiáveis, configure assinatura release persistente.

`applicationId`: `com.exemplo.exploradorzip` · `versionCode`: 9 · `versionName`: 2.7.0 · `targetSdk`: 35.

O projeto **não foi compilado nem testado em um Android real** nesta entrega; a estrutura e a sintaxe Java foram verificadas em ambiente sem Android SDK, mas a compilação completa precisa ocorrer no GitHub Actions. Não use auditorias como única forma de verificar arquivos importantes.
